Método

Cómo sacarles partido

Arranca el proyecto

Con Java 21 y Docker: docker compose up -d levanta PostgreSQL y ./mvnw spring-boot:run, la API en el puerto 8080.

Lee con el código al lado

Cada fragmento indica de qué fichero sale. Ábrelo en tu IDE y búscalo: el código de las lecciones es el del proyecto.

Prueba las peticiones

En peticiones.http hay una petición para cada caso, lista para lanzar desde IntelliJ o VS Code.

Haz el test al final

Responde antes de mirar la explicación: es donde más se aprende. Tu nota aparece en la tarjeta de la lección.

src/main/java/com/saseformacion/crud/
├── controller/   HTTP ↔ Java, @Valid, códigos de estado      00├── service/      reglas de negocio, transacciones, caché     01 · 05├── repository/   acceso a datos con Spring Data JPA          00 · 01├── model/        la entidad Producto                         00├── dto/          lo que entra y sale de la API (records)     02├── mapper/       conversión entidad ↔ DTO                    03├── exception/    excepciones y manejador global              04└── config/       CacheConfig (@EnableCaching)                05

Qué lleva el proyecto

  • Spring Boot 4.1 y Java 21, con Maven.
  • Spring Web MVC, Spring Data JPA con Hibernate, Bean Validation y Spring Cache.
  • PostgreSQL 17 en Docker.
  • Tests de cada capa: el controlador sin base de datos, el servicio contra PostgreSQL y el mapper sin Spring.
